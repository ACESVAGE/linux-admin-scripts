## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/ACESVAGE/linux-admin-scripts.git
cd linux-admin-scripts

# Make a script executable
chmod +x script-name.sh

# Run a script
./script-name.sh
```
