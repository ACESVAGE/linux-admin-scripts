## 📁 Repository Structure

```
linux-admin-scripts/
│
├── admin/                  # System administration scripts
│   ├── user-management/    # Create, delete, manage users & groups
│   ├── disk-management/    # Disk usage, cleanup, partitioning
│   ├── network/            # Network config, monitoring, diagnostics
│   ├── backup/             # Backup and restore automation
│   └── monitoring/         # System health, logs, resource monitoring
│
├── cybersecurity/          # Cybersecurity & ethical hacking scripts
│   ├── recon/              # Reconnaissance & information gathering
│   ├── network-scanning/   # Port scanning, host discovery
│   ├── hardening/          # System hardening & security config
│   ├── log-analysis/       # Log parsing & threat detection
│   └── ctf/                # CTF (Capture The Flag) helper scripts
│
├── utils/                  # Shared utility functions & helpers
```
